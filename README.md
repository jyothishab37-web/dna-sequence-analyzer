# DNA Sequence Analyzer 🧬

This is a beginner-friendly bioinformatics project built using **Python** and **Flask**.
The application analyzes a DNA sequence and provides biological insights such as
mRNA transcription, protein translation, and GC content.

---

## 🚀 Features

- Accepts a DNA sequence (A, T, G, C)
- Converts DNA → mRNA
- Translates mRNA → Protein
- Displays amino acid **one-letter codes and full names**
- Calculates GC content percentage

---

## 🧪 Example

### Input DNA
ATGGCC

### Output
- DNA: ATGGCC  
- mRNA: AUGGCC  
- Protein: MA  
- Amino acids:  
  - M (Methionine)  
  - A (Alanine)  
- GC Content: 66.67%
